### Описание проекта    
Угадать загаданное компьютером число за минимальное число попыток.

:arrow_up:[к оглавлению](#Оглавление)


### Какой кейс решаем?    
Нужно написать программу, которая угадывает число менее чем за 20 попыток.

**Условия соревнования:**  
- Компьютер загадывает целое число от 1 до 100, и нам его нужно угадать. Под «угадать» подразумевается «написать программу, которая угадывает число».
- Алгоритм учитывает информацию о том, больше ли случайное число или меньше нужного нам.

**Метрика качества**     
Результаты оцениваются по среднему количеству попыток при 1000 повторений. Финальный результат должен быть меньше 20 попыток.

**Что практикуем**     
- Учимся писать хороший код на Python в соответствии со стандартами PEP8.
- Учимся фиксировать зависимости проекта с помощью `requirements.txt`.
- Осваиваем алгоритмы бинарного поиска для оптимизации вычислений.

:arrow_up:[к оглавлению](#Оглавление)


### Краткая информация о данных
В качестве тестовых данных используется массив из 1000 случайных целых чисел в диапазоне от 1 до 100 включительно. Массив генерируется с помощью функции `np.random.randint()`.
  
:arrow_up:[к оглавлению](#Оглавление)


### Этапы работы над проектом  
1. Изучение базового алгоритма случайного угадывания и оценка его эффективности (~100 попыток).
2. Разработка эффективного алгоритма угадывания на основе метода бинарного поиска (деление диапазона поиска пополам).
3. Интеграция нового алгоритма в функцию тестирования `score_game`.
4. Оформление проекта на GitHub в соответствии с правилами хорошего тона (аккуратный репозиторий, понятный README).

:arrow_up:[к оглавлению](#Оглавление)


### Результат  
Новый алгоритм, основанный на бинарном поиске, находит загаданное число в среднем за **5 попыток**, что значительно меньше установленного лимита в 20 попыток.

:arrow_up:[к оглавлению](#Оглавление)


### Выводы  
Применение правильного алгоритма (в данном случае бинарного поиска вместо случайного перебора) позволяет кардинально снизить вычислительную сложность задачи и сократить число итераций со 100 до 5.
